# 📊 Superstore Sales Dashboard – Power BI

An interactive Power BI dashboard developed using the **Superstore Sales Dataset** from Kaggle. This project demonstrates end-to-end business analysis by transforming raw sales data into actionable insights through KPIs, charts, and interactive dashboards.

## Features

* Executive KPI Dashboard
* Sales & Profit Analysis
* Regional Performance
* Category & Sub-Category Analysis
* Customer Segment Insights
* Shipping Mode Analysis
* Time-Series Sales Trends
* Interactive Slicers and Filters

## Tools Used

* Power BI
* Power Query
* DAX
* Data Modeling

## Dataset

Superstore Sales Dataset (Kaggle):
https://www.kaggle.com/datasets/vivek468/superstore-dataset-final
